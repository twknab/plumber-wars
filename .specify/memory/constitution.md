# Plumber Wars Constitution
Version 1.0.0 · Ratified 2026-09-26

1. Mobile first: landscape, visible multi-touch controls, keyboard parity, pause on backgrounding.
2. Joyful underdogs: G’s Plumbing / COOL HOMIES are heroes; Northwest is fictional. Animals escape unharmed.
3. Complete loop: Dalton, Milan, or Jared; drive; repair; gain territory. Five levels, three households each. Retry only the active household.
4. Fair pressure: readable hazards, real rival progress, customer patience, instructions before timers.
5. Inclusive neighbors: families have personalities; identity is never a punchline. Replaceable placeholder portraits.
6. Portable: browser-first Phaser. Native/Steam packaging and device certification are later deliverables.
7. Evidence: keep specifications and verification current; distinguish verified work from future ambitions.
